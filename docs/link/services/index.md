# Link Services

Production-ready microservices that power The Link integration fabric.

## Overview

The Link Services are a suite of focused microservices that connect digital asset rails with legacy and modern financial systems. Each service includes clear getting started guides, complete API references, error handling, and FAQs.

## Service Catalog

### Core
- **What it is:** Central orchestrator for transactions, balances, ledgers, and asset management across the platform.
- **Docs:** [Getting Started](./core/getting-started.md) · [API Reference](./core/index.md) · [Error Handling](./core/error-handling.md) · [FAQ](./core/faq.md)

### Account Manager
- **What it is:** APIs for managing customers, participants, accounts, and wallets.
- **Docs:** [Getting Started](./account_manager/getting-started.md) · [API Reference](./account_manager/api-reference/index.md) · [Error Handling](./account_manager/error-handling.md) · [FAQ](./account_manager/faq.md)

### Blockchain Listener
- **What it is:** Background listeners and APIs for blockchain events, address and wallet management, queue/Redis operations, and system health.
- **Docs:** [Getting Started](./blockchain_listener/getting-started.md) · [API Reference](./blockchain_listener/api-reference/index.md) · [Error Handling](./blockchain_listener/error-handling.md) · [FAQ](./blockchain_listener/faq.md)

### Quote
- **What it is:** Real-time digital asset pricing and provider aggregation (CoinMarketCap, Pyth, etc.).
- **Docs:** [Getting Started](./quote/getting-started.md) · [API Reference](./quote/api-reference/rates.md) · [Error Handling](./quote/error-handling.md) · [FAQ](./quote/faq.md)

### Router
- **What it is:** Financial message routing with modules for accounts, verification, wallets, and health monitoring.
- **Docs:** [Getting Started](./router/getting-started.md) · [API Reference](./router/api-reference/index.md) · [Error Handling](./router/error-handling.md) · [FAQ](./router/faq.md)

### Tracker
- **What it is:** Centralized activity logging and event monitoring with advanced filtering and real-time streaming.
- **Docs:** [Getting Started](./tracker/getting-started.md) · [API Reference](./tracker/api-reference/log-messages.md) · [Error Handling](./tracker/error-handling.md) · [FAQ](./tracker/faq.md)

### Verify
- **What it is:** Sanctions screening, webhook delivery, and verification job orchestration.
- **Docs:** [Getting Started](./verify/getting-started.md) · [API Reference](./verify/api-reference/index.md) · [Error Handling](./verify/error-handling.md) · [FAQ](./verify/faq.md)
